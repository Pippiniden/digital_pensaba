# 原作データのプリセット（presets/original）

このエンジンをコピーして使う人が、原作のサーヴァントとマスターをすぐ置けるようにした控えです。
ゲームはこのフォルダを読み込みません（`js/` の既定データとは別物）。**既存の `js/units.js` / `js/masters.js` はそのまま**です。

| ファイル | 中身 |
|---|---|
| `units.js` | サーヴァント9騎：アルトリア(C5)・エミヤ・クー・フーリン・メドゥーサ・メディア・佐々木小次郎・呪腕のハサン・ヘラクレス・マシュ |
| `masters.js` | マスター7人：遠坂凛・衛宮切嗣・衛宮士郎・藤丸立香・セレニケ・間桐慎二・間桐雁夜 |
| `img/units/` | 上記の画像（`{id}.webp`。IDは各データの `id` と同じ） |

どちらも、ペンシルエディタの「書き出し」と同じ形式（`DEFAULT_UNITS` / `DEFAULT_MASTERS`）です。

## 使い方

**ゲームの既定データにする**（データを入れ替える）
1. `presets/original/units.js` を `js/units.js` に、`presets/original/masters.js` を `js/masters.js` に上書きコピーする
2. `presets/original/img/units/*.webp` を `img/units/` にコピーする

**今のデータに足す**
- エディタを開き、「読み込み」で `units.js` / `masters.js` を選ぶと、編集中の一覧に取り込めます。

## 注意
- `id` は重複させないでください（サーヴァントとマスターの間でも重複不可）。
- ブラウザにエディタの「ゲームに反映」データが残っていると、そちらが `js/` の既定データより優先されます。反映されないときはエディタの「標準データに戻す」を押してください。
- このプリセットは、作成時点の `js/` のデータの複製です。`js/` 側を調整しても、ここは自動では変わりません。
