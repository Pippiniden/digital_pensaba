# PENCIL DUEL UIデザイン指針（ボタン編）

FGO風の「濃紺の夜空 × 金の細線」の世界観を壊さず、迷わず押せるUIにするための約束ごと。
実装は `css/buttons.css`（ボタンの見た目はここだけで決める）。

## 1. 前のボタンが「ダサく」見えた理由

| 症状 | 原因 |
|---|---|
| 色に違和感がある | 濃紺＋金のパレットに無い **水色（シアン）・白銀・橙・赤の下線** が入り、画面ごとに別のゲームに見えた |
| まとまりがない | ヘキサ（左右が尖る）・真珠の丸・白い板・青い四角・タブ…と **形が5種類以上** 混在 |
| 何を押せばいいか分からない | 「選択中の選択肢」と「次へ進む決定ボタン」が **同じ金の塗り** で区別できない |
| 主役が目立たない | 一番目立つ白銀を「戻る」「おまかせ」など脇役に使い、決定より目を引いていた |
| 大きさがバラバラ | 縁を `box-shadow` を3重に重ねて太らせたので、同じ役割でも見た目の大きさと余白が場所ごとに違う |
| 変更漏れ | 元の `base.css` / `game.css` / `editor.css` に旧ルールが残り、上書きの当て方で場所ごとに新旧が混ざった |

## 2. 原則

1. **色は3つの役割だけ**：地＝濃紺、飾り・強調＝金、文字＝白〜青灰。カードの赤・青・緑は「コマンドの色」専用で、ボタンには使わない。
2. **形は1つ**：角をわずかに丸めた長方形（半径3px）＋金の細い枠。パネル（`.card`）と同じ「金の外線＋暗い内線」の二重枠で、画面の中に溶け込ませる。
3. **金で塗るのは「その画面で一番押してほしいボタン」1つだけ**。塗りの金は「進む」の意味に固定する。
4. **選択状態は塗らずに光らせる**：選ばれた選択肢は「金の枠＋金の文字＋◆」。塗りは決定ボタンだけなので、選択と決定が混ざらない。
5. **脇役は静かに**：戻る・閉じる・ヘッダーの設定類は枠線だけの控えめなボタン。目立たせない。
6. **大きさは3段階だけ**：小（28px・カード上やヘッダー）／中（34px・標準）／大（46px・メニューパネル）。役割ではなく「置き場所」で決める。
7. **反応は共通**：ホバーで枠が明るい金になり少し光る／押すと1px沈む／無効は半透明。キーボード操作時は金の外枠（`:focus-visible`）。

## 3. ボタンの種類

| 種類 | 見た目 | 使う所 | クラス |
|---|---|---|---|
| 決定（Primary） | 金の塗り＋濃い文字（明朝） | 決定・次へ・はじめる・ロール・攻撃 | `.primary`（大きめは `.big`）、メニュー内は `.gbtn.go` |
| 通常（Secondary） | 濃紺の地＋金の細枠 | おまかせ・宝具の使用など普通の操作 | 指定なし（`button` の既定） |
| 控えめ（Ghost） | 半透明の地＋青灰の細枠 | 戻る・閉じる・ヘッダーの設定類 | `.back`（‹ 付き）・`.ghost`・ヘッダー内は自動 |
| 選択肢（Choice） | 通常より暗い。選択中は金の枠・金の文字・◆ | ルール・CPUの強さ・設定のON/OFF | メニュー内 `.gbtn`（選択中 `.p`）、並びは `.seg`（選択中 `.on`） |
| タブ | 文字だけ。選択中は金の文字＋下線 | リザルトの詳細・エディタの左列 | `.rtabs` / `.edtabs` / `[role=tab]` |

タイトル画面の大メニュー（`.topmenu`）は「看板」なので別扱い（金の細線に挟まれた文字だけ）。

### 部品

| 部品 | ルール |
|---|---|
| スキル（`.sk`） | 使える＝金の細枠、使えない＝沈んだ枠で薄く、使用済み＝さらに薄く取り消し線。宝具だけはコマンド色（Buster赤など）を使う（カードの色と同じ意味なので例外） |
| ⓘ・× | 濃紺の小さな丸／四角＋金の細枠。スキルが使えるときの ⓘ（`.canskill`）だけ金で光らせる |
| 外部リンク（`.linkbtn`） | 通常ボタンと同じ形で文字だけ金 |
| 令呪・マスターの行動 | 選択肢なので全部「通常」。定番の「補助」だけ金 |

## 4. 並べ方

- 決定ボタンは並びの **右端**（縦並びなら一番下）。戻るは左端（縦並びなら一番上の左）。
- ボタン同士の間隔は 8px（同じグループ）／16px以上（別グループ）。
- 1つのパネルに金の塗りは1つまで。2つ目が要るなら、どちらかが本当の主役ではない。
