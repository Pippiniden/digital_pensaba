# 条件つきセリフ（condLines）案

各キャラのリンク先（kagemiya@ふたば wiki ほか）の「人物・性格」「因縁キャラ」を読んで、**今のロスターにいる相手との関係**を中心に考えた案です。
すでに入っている condLines と重なるものは外しています。まだゲームのデータには入れていません。

- 場面：`start` 戦闘開始 / `attack` 攻撃 / `extra` EX / `defeat` 敗退 / `win` 勝利（マスターは `start` / `win` / `defeat` など）
- 条件：**敵に** = `who:'enemy'`、**相手** = `who:'other'`（defeat はとどめを刺した相手、attack は攻撃対象）、**味方に** = `who:'ally'`。`id` / `trait` / `cls` は condLines の条件の種類（cond.k）です
- 戦闘開始と勝利は、`other` だと「先頭の相手」や「最後に倒した相手」でしか出ないので、基本は `enemy`（敵のだれか）にしています
