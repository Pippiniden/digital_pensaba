# マスター作成プロンプト

> ふつうは、これと資料・見本・設定シートをまとめた `master-kit.md`（`node tools/llm-pack.js` が作る）を AI に渡します。
> 「## ここからプロンプト」より下が、AI に読ませる本文です。
> サーヴァントを作るときは、こちらではなく `prompt.md`（まとめた版は `kit.md`）を使います。

## ここからプロンプト

あなたは、6面の鉛筆をサイコロにして戦う対戦ゲーム「PENSABA DUEL」の**マスター（泥ペンマス）のデータ**を作る担当です。
渡された設定シートの人物を、ゲームにそのまま読み込める **JSON** にしてください。

### マスターでないものを頼まれたら

このキットは**マスター専用**です。設定シートが**サーヴァント**（鉛筆の面・スキル3つ・宝具を持って戦う英霊）を頼んでいるときは、マスターとして作らずに、JSON を出さないで次のように伝えてください。

> サーヴァントはこのキットでは作れません。サーヴァント作成キット（https://pippiniden.github.io/digital_pensaba/docs/llm/kit.md ）を使ってください。

### 渡す資料

| 資料 | 中身 |
|---|---|
| `master-reference.md` | マスターシートの決まり（HP・補助の面の数・入れてはいけない効果・目安値）、令呪の上限、効果と対象の一覧、汎用令呪の例、使用済みID |
| `master-template.json` | 書式の見本（コスト3・シートどおりのマスター） |
| 設定シート | 作ってほしい人物の設定 |

`master-reference.md` にない効果のキー・対象・項目は**使わないでください**。

### ゲームの仕組み（マスターに関係するところだけ）

- マスターは、サーヴァントと組んで戦う「後ろの人」です。マスタールール（1対1＋マスター）と、マスターチーム（3対3＋マスター、マスター込みで合計コスト13まで）で使います。
- マスターのコストも編成のコストに入ります。**コストが高いマスターほど、組めるサーヴァントが弱くなります。** マスターの強さはコストに見合っていなければいけません。
- 毎ターン1回、マスターは次のどれかをします。
  - **補助**：マスターの鉛筆（6面）を振り、出た面の効果を自軍にかける。**効果はそのターンだけ**（`turns` を書かない）。何も書いていない面は「無」（はずれ）。
  - **令呪**：3つの令呪から1つを使う。1試合1回だけの切り札。
  - （マスタールールだけ）敵を直接攻撃する・退避する。
- マスターにもHPがあり、マスタールールでは攻撃されることがあります。HPが0になると瀕死になり、自軍のサーヴァントが大きなダメージを受けます。

### いちばん大事なこと：設定を「そのまま」効果にしない

マスターは、サーヴァントを**少し手助けする**役です。設定の「最強の魔術師」「時間を止める」「一撃で倒す」は、ゲームでは**その方向に少し寄せる**だけにしてください。

- **強い設定はコストで表す。** 名のある大魔術師はコスト4〜5にする。補助の面の数・値はコストで決まっているので、それを超えて盛らない。
- **補助の面は「当たり」の数がコストで決まっている**（4番の面＋コストと同じ数の面だけに効果。残りは「無」）。全部の面に効果を入れない。
- **即死・無敵・スタン・NPの即時増加は補助に入れない。** スタン・無敵は令呪でだけ使える。
- **令呪は1回きりの切り札**だが、効果は1〜3個。設定の要素を1つの令呪に詰め込まない。
- 必ず「資料」の **マスターシートの決まり** と **令呪の上限** を守る。

設定を効果に置き換えるときの目安：

| 設定 | ✕ やりがち | ○ こう置き換える |
|---|---|---|
| 天才魔術師・何でもできる | 6面すべてに効果 | 当たりの面はコストの数だけ。4番を「秘術」にして少し強く |
| 時間停止・束縛の魔術 | 補助にスタン | 補助は攻撃ダメージ-・クリティカル率ダウン、スタンは令呪に1T で |
| 呪い殺す・暗殺 | 即死 | 補助で敵単体ダメージ（目安値）、令呪で敵単体ダメージ＋毒 |
| 無限の魔力 | 補助で NP+30% | 補助は「攻撃時NP獲得」（目安値）、令呪で NP+30〜50% |
| 鉄壁の結界 | 補助に無敵 | 補助は被ダメージ-（目安値）、令呪で無敵 1T |

### 作り方の手順

次の順に決めてください。考えた過程は出力しなくてかまいません。

1. **コンセプト**：設定シートから、支え方を1行にまとめる（例：「攻撃強化で押す」「回復と弱体解除で粘る」「敵マスターを狙撃する」）。
2. **コスト**：設定シートの指定に従う。「おまかせ」なら0〜5から選ぶ（多くは2〜4）。
3. **HP**：コスト×100 を基準に ±100 まで、50刻みで補正する。
4. **補助の6面**：
   - **4番の面（faces の4つ目）は必ず効果を入れる**（ほかの面より強め。目安値の「4番」の列）。
   - 4番以外で効果を入れる面は、**コストと同じ数**だけ（コスト0なら0、コスト5なら5つ全部）。残りの面は `{"label":"無","eff":[]}`。
   - 値は「目安値」の表に合わせる（4番以外／4番、コスト5は★5の列）。味方単体（`ally_svt`）にするなら表の「単体」の分だけ上げてよい。
   - 効果は**そのターンだけ**なので `turns`・`times` は書かない（「入れてはいけない効果」「リミット枠」の決まりも守る）。
   - 同じ種類の効果（効果・色・対象が同じ）は補助全体で3つまで。
5. **令呪3つ**：「汎用令呪の例」の値を目安に、設定に合った名前と効果にする。
   - 1つの令呪に効果は1〜3個。強化は `turns:1` が基本。
   - 「令呪の上限」を超えない。
6. **セリフ**：`lines` の `support`（補助）・`attack`（攻撃）・`spell`（令呪使用）を、人物の口調で1〜3種類ずつ。面や令呪だけの専用セリフは、その面・令呪に `"line":["…"]` で付けてよい。
7. **強さの収支**：`memo` に「コンセプト／強み／その代わりに弱くしたところ」を1〜2行で書く。弱くしたところが書けないなら、強すぎるので見直す。
8. **ID**：`id` は半角英小文字・数字・`_`・`-` だけで、`m_` で始め、「使用済みのID」と重ならないもの。

### 書式の決まり（間違えやすいところ）

- 形は `{"id","name","cost","hp","memo","lines":{support,attack,spell},"faces":[6個],"spells":[3個]}`。`cls` や `traits` は書かない。
- `faces` は必ず6個、各面は `{"label":"面の名前","eff":[…]}`。効果がない面も `"label":"無","eff":[]` と書く。
- `spells` は必ず3個、各令呪は `{"name":"令呪の名前","eff":[…]}`。読みを付けたいときは `"ruby":"よみがな"` を足せる（任意。カットインで名前の上に出る）。
- 効果：`{"k":キー,"t":対象,"v":値}`。値を使わない効果も `"v":0` と書く。`"chance":N` は「ロールN以下で成功」。
- 対象は資料の「対象（マスター用）」から選ぶ。サーヴァント用の `picked`・`target`・`ally_other` は使えない。
- 敵1体を狙うなら `enemy_svt`、味方1騎を選ぶなら `ally_svt`。スター獲得（`star`）の対象は `master`。
- `dmg`（ダメージ）はマスターでは補助・令呪で使える（固定ダメージ）。
- 数値は数（"30" ではなく 30）。コメントは書かない。画像の位置（`fit`）・リンク（`link`）は書かない。

### 出力

- **JSON だけ**を、```json のコードブロック1つで出力する。前後に説明を書かない。
- 1人ならオブジェクト `{…}`、複数人なら配列 `[{…},{…}]`。
- 出力の前に、次を自分で確かめる。
  - [ ] faces が6個、spells が3個
  - [ ] HP がコスト×100 ±100（50刻み）
  - [ ] 4番の面に効果があり、4番以外で効果のある面がコストと同じ数
  - [ ] 補助に即死・無敵・スタン・NPの即時増加がない。リミット枠の効果は決まりの数まで
  - [ ] 補助の値が目安値以下。補助に turns・times を書いていない
  - [ ] 令呪が「令呪の上限」を守っている（効果3つまで・即死なし・強い効果は 1T か1回）
  - [ ] 効果のキー・対象がすべて資料にある
  - [ ] `memo` に強みと、その代わりに弱くしたところを書いた
  - [ ] id が使用済みのIDと重ならない
