# AI（LLM）にサーヴァントを作らせる

AI にキャラクターの設定を渡し、ゲームにそのまま読み込めるデータ（JSON）を書かせるための資料です。

## ファイル

| ファイル | 中身 | 作り方 |
|---|---|---|
| `prompt.md` | AI への指示（作り方の手順・書式の決まり・出力前の点検） | 手で書く |
| `reference.md` | 基準値・効果の一覧・対象の一覧・今のキャラでの効果の使われ方・クラス・属性・使用済みID | `node tools/llm-pack.js` が作る（手で直さない） |
| `template.json` | 書式の見本（コスト3・基準どおり。検証エラーなし・勝率約50%） | 手で書く |
| `sheet.md` | 作ってほしいキャラの設定を書く用紙 | 使う人が記入 |

## 使い方

1. 基準値（`js/unit-ref.js`）や効果（`js/rules.js` の `FX`）を変えたら、資料を作り直す。

   ```
   node tools/llm-pack.js
   ```

2. `sheet.md` に設定を書く。
3. AI に `prompt.md`・`reference.md`・`template.json`・記入した `sheet.md` を渡す（ファイルを添付するか、全文を貼る）。
4. AI が出した JSON をファイル（例：`new.json`）に保存し、検査する。読み込みエラー・エディタの検証・基準値との比較が出る。

   ```
   node tools/llm-pack.js --check new.json
   ```

5. 強さを測る（基準どおりのテスト用キャラだけの環境に1体入れた勝率。今のキャラは対戦に入れない。目安 50%±3%）。

   ```
   node tools/ref-check.js --add new.json
   ```

6. エディタ（`editor.html`）の「1体を読み込み」で `new.json` を取り込み、画像やセリフを整えて「ゲームに反映」する。

検査や勝率で問題が出たら、その結果をそのまま AI に渡して「この結果を見て直して」と頼むと直しやすくなります。

## 注意

- `reference.md` の「使用例」は、今のキャラ（原作キャラを除く）が実際に使っている値です。強さの保証ではありません。
- 勝率は CPU（つよい）同士の 3on3 で測っています。スキルの使いどころなど、CPU が苦手な効果は実際より弱く出ることがあります。
