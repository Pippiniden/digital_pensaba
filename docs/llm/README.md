# AI（LLM）にサーヴァントを作らせる

AI にキャラクターの設定を渡し、ゲームにそのまま読み込めるデータ（JSON）を書かせて、Discord で導入を申請するための仕組みです。

## 申請する人の流れ

1. 申請ツール（`submit.html`。公開版は https://pippiniden.github.io/digital_pensaba/submit.html ）を開き、**申請キット（`kit.md`）** をダウンロードする。
2. ChatGPT・Claude・Gemini などの AI に `kit.md` を渡し（プロジェクトの資料に入れるか、チャットに添付）、キャラクターの設定を送る。キャラシートの貼り付けでよい。
3. AI が返した JSON を申請ツールに貼り付けて「検査する」。エラー・基準値との比較・鉛筆の面とスキルのプレビューが出る。
4. 「勝率を測る」で強さを確かめる（基準どおりのテスト用キャラだけの環境に1体入れて、各3000試合。今のキャラは対戦に入れない。目安 50%±3%）。
5. 問題があれば「AIに直してもらう文をコピー」して AI に送り、直った JSON を貼り直す。
6. 出典URLを入れ、「JSONを保存」したファイルを添付して、「Discord用の文をコピー」した文を Discord の申請先に送る。

申請ツールはデータをどこにも送信しません（ブラウザの中だけで検査・測定する）。

## 受け取る人（管理者）の流れ

1. 添付の JSON をエディタ（`editor.html`）の「1体を読み込み」で取り込む。
2. 画像（`img/units/{id}.webp`）を置き、必要なら数値やセリフを整える。
3. `units.js` を書き出して `js/units.js` を差し替える。

手元で確かめ直すなら `node tools/llm-pack.js --check new.json`（検査）と `node tools/ref-check.js --add new.json`（勝率。試合数は `-n`）。

## ファイル

| ファイル | 中身 | 作り方 |
|---|---|---|
| `kit.md` | AI に渡す1ファイル（下の4つをまとめたもの） | `node tools/llm-pack.js` が作る |
| `prompt.md` | AI への指示（作り方の手順・書式の決まり・出力前の点検） | 手で書く |
| `reference.md` | 基準値・効果の一覧・対象の一覧・今のキャラでの効果の使われ方・クラス・属性・使用済みID | `node tools/llm-pack.js` が作る（手で直さない） |
| `template.json` | 書式の見本（コスト3・基準どおり。検証エラーなし・勝率約50%） | 手で書く |
| `sheet.md` | 設定シート（設定の書き方の例） | 手で書く |

**基準値（`js/unit-ref.js`）・効果（`js/rules.js` の `FX`）・キャラ（`js/units.js`）・`prompt.md` などを変えたら、`node tools/llm-pack.js` で `reference.md` と `kit.md` を作り直してからプッシュしてください。**
使用済みIDや「使われ方」も今のキャラから作るので、キャラを追加したときも作り直すと重複IDを防げます。

## 注意

- `reference.md` の「使用例」は、今のキャラ（原作キャラを除く）が実際に使っている値です。強さの保証ではありません。
- 勝率は CPU（つよい）同士の 3on3 で測っています。CPU が使いこなせない効果は、実際より弱く出ることがあります。
- 勝率の測定には http で開く必要があります（`file://` ではワーカーが動きません）。
